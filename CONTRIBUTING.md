# Contributing

Thank you for helping make manuscript workflows calmer and more transparent.

## Before opening a change

1. Search existing issues.
2. For substantial features, open an issue describing the author problem before implementation.
3. Keep integrations optional and preserve a useful local-first core.
4. Do not add analytics, tracking or an external service without documenting its data flow.
5. Treat recommendations as leads with explicit provenance, not verified scholarly evidence.

## Local checks

```bash
npm install
npm run check
```

Pull requests should explain the author need, user-visible change, privacy implications and validation performed.
