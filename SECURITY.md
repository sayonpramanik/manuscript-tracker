# Security policy

## Supported version

Security fixes are applied to the latest release on the default branch.

## Reporting

Please do not publish a vulnerability, exposed credential or private manuscript as a public issue. Contact the maintainer privately through their GitHub profile and include reproduction steps without real confidential data.

## Deployment responsibilities

The default local-first MVP is not a regulated records system. Operators adding accounts or shared persistence are responsible for authentication, authorization, encryption, backups, audit logs, retention rules, dependency updates and applicable institutional policies.
